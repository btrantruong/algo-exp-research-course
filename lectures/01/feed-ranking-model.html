Where does machine learning enter?

Some information can be observed directly (e.g., following). Others are not, and must be estimated from earlier examples. These include post features, such as emotionality or constructiveness, and a user’s future reaction—whether the person will like the next post.

Each point is an earlier post whose outcome is now known.

A simple linear model learns a small contribution for each input.

Estimated coefficients (β): these values are not observed in a row. Training estimates them from the past outcomes.
